Detection & violation rules

Persistence: a worker must stay non-compliant this long before an incident is recorded. Cooldown: minimum time before the same worker is recorded again for the same violation type. Confidence: minimum score for a detection to count. People and other objects use the first value; helmets and vests use the second, lower one because they are small and score lower on distant workers. Both apply immediately to running cameras.
